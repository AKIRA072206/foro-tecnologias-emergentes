==================================================

GUÍA RÁPIDA DE MIGRACIÓN Y DESPLIEGUE - OPENCODE

==================================================



1. REQUISITOS PREVIOS

--------------------------------------------------

- Node.js instalado (versión 18 o superior recomendada).

- Cuenta activa en Vercel o plataforma de despliegue elegida.

- Repositorio configurado en Git.



2. CONFIGURACIÓN DE ARCHIVOS

--------------------------------------------------

- Asegurarse de que el archivo vercel.json tenga la propiedad `includeFiles` correctamente definida como string:

  "includeFiles": "views/**,public/**"

- Verificar las variables de entorno (.env) necesarias para producción.



3. PROCESO DE DESPLIEGUE

--------------------------------------------------

- Instalar dependencias: npm install

- Ejecutar pruebas locales: npm run dev

- Realizar commit de los cambios y desplegar.
