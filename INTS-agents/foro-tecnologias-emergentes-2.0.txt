# II Foro de Tecnologías Emergentes: Inteligencia Artificial

Aplicación web MVC en PHP nativo + PostgreSQL para registro de participantes, control de asistencia y emisión de certificados digitales.

**Fecha del evento:** 06 de noviembre de 2026 · 8:00 AM

## Requisitos

- PHP 8.1+ con extensión `pdo_pgsql`
- PostgreSQL 13+
- Apache con `mod_rewrite` **o** servidor embebido de PHP

## Instalación rápida

### 1. Clonar el repositorio

```bash
git clone <URL_DEL_REPO>
cd foro-tecnologias-emergentes
```

### 2. Base de datos (copia incluida)

En la **raíz del proyecto** está el archivo `foro_backup.sql` (volcado completo de la BD).

```bash
# Crear la base (nombre en minúsculas en PostgreSQL)
psql -U postgres -c "CREATE DATABASE foro;"

# Restaurar esquema + datos
psql -U postgres -d foro -f foro_backup.sql
```

Si prefieres solo el esquema vacío (sin datos):

```bash
psql -U postgres -d foro -f database/schema.sql
```

### 3. Configuración

Edite `config/database.php` según su entorno:

| Variable / clave | Valor de ejemplo |
|------------------|------------------|
| host             | localhost        |
| port             | 5432             |
| dbname           | foro             |
| user             | postgres         |
| password         | *su contraseña*  |

Credenciales de logística (`config/auth.php`):

| Campo        | Valor por defecto |
|--------------|-------------------|
| Usuario      | `logistica`       |
| Contraseña   | `foro2026`        |

> En modo prueba, `forzar_asistencia` está en `true` para poder marcar asistencia y generar certificados sin esperar al 06/11/2026. Cámbielo a `null` en producción.

### 4. Ejecutar

```bash
cd public
php -S localhost:8080 router.php
```

Abra http://localhost:8080

| Quién        | URL                          |
|--------------|------------------------------|
| Estudiantes  | http://localhost:8080/registro |
| Logística    | http://localhost:8080/login    |

## Módulos

- **Registro público** — inscripción de participantes
- **Logística** (login) — listado en vivo + select ¿Vino? (bloqueado al confirmar)
- **Certificados** — vista imprimible y descarga PDF

## Estructura

```
foro_backup.sql      # Copia de la base de datos (raíz)
config/              # database.php, auth.php
app/controllers/
app/models/
app/views/
app/core/
public/              # Front controller, CSS, JS, imágenes
database/schema.sql  # Esquema vacío
```

## Seguridad

- PDO + prepared statements
- CSRF en formularios y AJAX
- Validación cliente/servidor
- Constraints en PostgreSQL
- Asistencia irreversible una vez marcada como "Sí"

<?php

declare(strict_types=1);

namespace App\Controllers;

use App\Core\Auth;
use App\Core\Controller;

class AuthController extends Controller
{
    public function loginForm(): void
    {
        if (Auth::check()) {
            $this->redirect('/logistica');
        }

        $this->view('auth/login', [
            'title'   => 'Acceso Logística',
            'page'    => 'login',
            'csrf'    => $this->csrfToken(),
            'error'   => null,
            'usuario' => '',
        ]);
    }

    public function login(): void
    {
        if (!$this->isPost()) {
            $this->redirect('/login');
        }

        $csrf = (string) $this->input('_csrf', '');
        if (!$this->verifyCsrf($csrf)) {
            $this->view('auth/login', [
                'title'   => 'Acceso Logística',
                'page'    => 'login',
                'csrf'    => $this->csrfToken(),
                'error'   => 'Token de seguridad inválido. Recargue la página.',
                'usuario' => '',
            ]);
            return;
        }

        // Pequeña pausa anti fuerza bruta
        usleep(250000);

        $usuario = trim((string) $this->input('usuario', ''));
        $password = (string) $this->input('password', '');

        if (!Auth::attempt($usuario, $password)) {
            $this->view('auth/login', [
                'title'   => 'Acceso Logística',
                'page'    => 'login',
                'csrf'    => $this->csrfToken(),
                'error'   => 'Usuario o contraseña incorrectos.',
                'usuario' => $usuario,
            ]);
            return;
        }

        $this->redirect('/logistica');
    }

    public function logout(): void
    {
        Auth::logout();
        $this->redirect('/login');
    }
}

<?php

declare(strict_types=1);

namespace App\Controllers;

use App\Core\Auth;
use App\Core\Controller;
use App\Models\EstudianteModel;
use Throwable;

class CertificadoController extends Controller
{
    private function requireAuth(): void
    {
        if (!Auth::check()) {
            $this->redirect('/login');
        }
    }

    public function index(): void
    {
        $this->requireAuth();

        $this->view('certificados/index', [
            'title'   => 'Consulta de Certificados',
            'page'    => 'certificados',
            'csrf'    => $this->csrfToken(),
            'mensaje' => null,
            'tipo'    => null,
        ]);
    }

    public function buscar(): void
    {
        $this->requireAuth();

        $cedula = preg_replace('/\D+/', '', (string) $this->input('cedula', '')) ?? '';

        if ($cedula === '' || !preg_match('/^[0-9]{6,10}$/', $cedula)) {
            $this->view('certificados/index', [
                'title'   => 'Consulta de Certificados',
                'page'    => 'certificados',
                'csrf'    => $this->csrfToken(),
                'mensaje' => 'Ingrese una cédula válida (solo números, máximo 10 dígitos).',
                'tipo'    => 'error',
            ]);
            return;
        }

        try {
            $modelo = new EstudianteModel();
            $estudiante = $modelo->buscarPorCedula($cedula);

            if ($estudiante === null) {
                $this->view('certificados/index', [
                    'title'   => 'Consulta de Certificados',
                    'page'    => 'certificados',
                    'csrf'    => $this->csrfToken(),
                    'mensaje' => 'No se encontró un registro con esa cédula.',
                    'tipo'    => 'error',
                ]);
                return;
            }

            $asistio = filter_var($estudiante['asistio'], FILTER_VALIDATE_BOOLEAN);
            if (!$asistio) {
                $this->view('certificados/index', [
                    'title'   => 'Consulta de Certificados',
                    'page'    => 'certificados',
                    'csrf'    => $this->csrfToken(),
                    'mensaje' => 'El participante aún no tiene asistencia confirmada. El certificado no está disponible.',
                    'tipo'    => 'error',
                ]);
                return;
            }

            $this->redirect('/certificados/' . (int) $estudiante['id']);
        } catch (Throwable $e) {
            $this->view('certificados/index', [
                'title'   => 'Consulta de Certificados',
                'page'    => 'certificados',
                'csrf'    => $this->csrfToken(),
                'mensaje' => 'Error al consultar el certificado.',
                'tipo'    => 'error',
            ]);
        }
    }

    public function ver(string $id): void
    {
        $this->requireAuth();

        $estudianteId = filter_var($id, FILTER_VALIDATE_INT);
        if ($estudianteId === false || $estudianteId <= 0) {
            http_response_code(404);
            echo 'Certificado no encontrado.';
            return;
        }

        try {
            $modelo = new EstudianteModel();
            $estudiante = $modelo->buscarPorId((int) $estudianteId);

            if ($estudiante === null) {
                http_response_code(404);
                echo 'Participante no encontrado.';
                return;
            }

            $asistio = filter_var($estudiante['asistio'], FILTER_VALIDATE_BOOLEAN);
            if (!$asistio) {
                http_response_code(403);
                $this->view('certificados/index', [
                    'title'   => 'Consulta de Certificados',
                    'page'    => 'certificados',
                    'csrf'    => $this->csrfToken(),
                    'mensaje' => 'No es posible emitir el certificado: la asistencia no está confirmada.',
                    'tipo'    => 'error',
                ]);
                return;
            }

            $this->view('certificados/ver', [
                'title'       => 'Certificado de Asistencia',
                'page'        => 'certificado-print',
                'estudiante'  => $estudiante,
                'eventoFecha' => '06 de noviembre de 2026',
                'eventoTitulo'=> 'II Foro de Tecnologías Emergentes: Inteligencia Artificial',
            ], null);
        } catch (Throwable $e) {
            http_response_code(500);
            echo 'Error al generar el certificado.';
        }
    }
}

<?php

declare(strict_types=1);

namespace App\Controllers;

use App\Core\Auth;
use App\Core\Controller;
use App\Models\AsistenciaModel;
use App\Models\EstudianteModel;
use Throwable;

class LogisticaController extends Controller
{
    private function requireAuth(): void
    {
        if (!Auth::check()) {
            if ($this->isAjax()) {
                $this->json(['ok' => false, 'mensaje' => 'Sesión expirada. Inicie sesión nuevamente.'], 401);
            }
            $this->redirect('/login');
        }
    }

    public function index(): void
    {
        $this->requireAuth();

        $estudiantes = [];
        $error = null;

        try {
            $modelo = new EstudianteModel();
            $estudiantes = $modelo->listarTodos();
        } catch (Throwable $e) {
            $error = 'No se pudieron cargar los registros. Verifique la conexión a PostgreSQL.';
        }

        $asistenciaOk = Auth::asistenciaHabilitada();

        $this->view('logistica/index', [
            'title'              => 'Logística',
            'page'               => 'logistica',
            'csrf'               => $this->csrfToken(),
            'estudiantes'        => $estudiantes,
            'error'              => $error,
            'eventoFecha'        => '06 de noviembre de 2026',
            'eventoHora'         => '8:00 AM',
            'asistenciaHabilitada'=> $asistenciaOk,
            'usuario'            => Auth::user(),
        ]);
    }

    /** Listado JSON para refresco automático del panel */
    public function lista(): void
    {
        $this->requireAuth();

        try {
            $modelo = new EstudianteModel();
            $rows = $modelo->listarTodos();

            $data = array_map(static function (array $e): array {
                return [
                    'id'               => (int) $e['id'],
                    'cedula'           => (string) $e['cedula'],
                    'nombre'           => (string) $e['nombre'],
                    'apellido'         => (string) $e['apellido'],
                    'correo'           => (string) $e['correo'],
                    'telefono'           => (string) $e['telefono'],
                    'institution_name'   => (string) ($e['institution_name'] ?? 'No indicó institución'),
                    'institution_type'   => (string) ($e['institution_type'] ?? 'no_indico'),
                    'asistio'            => filter_var($e['asistio'], FILTER_VALIDATE_BOOLEAN),
                    'fecha_registro'     => (string) ($e['fecha_registro'] ?? ''),
                ];
            }, $rows);

            $this->json([
                'ok'                   => true,
                'asistencia_habilitada' => Auth::asistenciaHabilitada(),
                'total'                => count($data),
                'asistentes'           => count(array_filter($data, static fn($r) => $r['asistio'])),
                'estudiantes'          => $data,
            ]);
        } catch (Throwable $e) {
            $this->json(['ok' => false, 'mensaje' => 'No se pudo obtener el listado.'], 500);
        }
    }

    public function actualizarAsistencia(): void
    {
        $this->requireAuth();

        if (!Auth::asistenciaHabilitada()) {
            $this->json([
                'ok'      => false,
                'mensaje' => 'El control de asistencia se habilita el día del evento (06/11/2026).',
            ], 403);
        }

        if (!$this->isPost()) {
            $this->json(['ok' => false, 'mensaje' => 'Método no permitido.'], 405);
        }

        $raw = file_get_contents('php://input') ?: '';
        $jsonBody = json_decode($raw, true);
        $payload = is_array($jsonBody) ? array_merge($_POST, $jsonBody) : $_POST;

        $csrf = (string) ($payload['_csrf'] ?? '');
        if (!$this->verifyCsrf($csrf)) {
            $this->json(['ok' => false, 'mensaje' => 'Token de seguridad inválido.'], 403);
        }

        $id = filter_var($payload['id'] ?? null, FILTER_VALIDATE_INT);
        if ($id === false || $id <= 0) {
            $this->json(['ok' => false, 'mensaje' => 'Identificador de estudiante inválido.'], 422);
        }

        $asistioRaw = $payload['asistio'] ?? null;
        if (is_bool($asistioRaw)) {
            $asistio = $asistioRaw;
        } elseif (is_string($asistioRaw) || is_int($asistioRaw)) {
            $val = strtolower((string) $asistioRaw);
            if (in_array($val, ['1', 'true', 'yes', 'on', 'si', 'sí'], true)) {
                $asistio = true;
            } elseif (in_array($val, ['0', 'false', 'no', 'off'], true)) {
                $asistio = false;
            } else {
                $this->json(['ok' => false, 'mensaje' => 'Valor de asistencia inválido.'], 422);
            }
        } else {
            $asistio = filter_var($asistioRaw, FILTER_VALIDATE_BOOLEAN, FILTER_NULL_ON_FAILURE);
            if ($asistio === null) {
                $this->json(['ok' => false, 'mensaje' => 'Valor de asistencia inválido.'], 422);
            }
        }

        try {
            $estudiantes = new EstudianteModel();
            $actual = $estudiantes->buscarPorId((int) $id);

            if ($actual === null) {
                $this->json(['ok' => false, 'mensaje' => 'Estudiante no encontrado.'], 404);
            }

            $yaAsistio = filter_var($actual['asistio'], FILTER_VALIDATE_BOOLEAN);

            // Una vez marcada la asistencia (Sí), no se puede modificar
            if ($yaAsistio) {
                $this->json([
                    'ok'      => false,
                    'mensaje' => 'La asistencia ya fue confirmada y no se puede modificar.',
                    'data'    => ['id' => (int) $id, 'asistio' => true, 'bloqueado' => true],
                ], 409);
            }

            // Solo se permite confirmar asistencia (pasar a Sí)
            if (!(bool) $asistio) {
                $this->json([
                    'ok'      => true,
                    'mensaje' => 'Sin cambios: la persona aún no ha sido marcada como asistente.',
                    'data'    => ['id' => (int) $id, 'asistio' => false],
                ]);
            }

            $modelo = new AsistenciaModel();
            $resultado = $modelo->actualizarAsistencia((int) $id, true);

            if ($resultado === null) {
                $this->json(['ok' => false, 'mensaje' => 'Estudiante no encontrado.'], 404);
            }

            $this->json([
                'ok'      => true,
                'mensaje' => 'Asistencia confirmada: Sí vino. Este registro quedó bloqueado.',
                'data'    => array_merge($resultado, ['bloqueado' => true]),
            ]);
        } catch (Throwable $e) {
            $this->json(['ok' => false, 'mensaje' => 'Error al actualizar la asistencia.'], 500);
        }
    }

    public function eliminar(): void
    {
        $this->requireAuth();

        if (!$this->isPost()) {
            $this->json(['ok' => false, 'mensaje' => 'Método no permitido.'], 405);
        }

        $raw = file_get_contents('php://input') ?: '';
        $jsonBody = json_decode($raw, true);
        $payload = is_array($jsonBody) ? array_merge($_POST, $jsonBody) : $_POST;

        $csrf = (string) ($payload['_csrf'] ?? '');
        if (!$this->verifyCsrf($csrf)) {
            $this->json(['ok' => false, 'mensaje' => 'Token de seguridad inválido.'], 403);
        }

        $id = filter_var($payload['id'] ?? null, FILTER_VALIDATE_INT);
        if ($id === false || $id <= 0) {
            $this->json(['ok' => false, 'mensaje' => 'Identificador de asistente inválido.'], 422);
        }

        try {
            $modelo = new EstudianteModel();
            $actual = $modelo->buscarPorId((int) $id);

            if ($actual === null) {
                $this->json(['ok' => false, 'mensaje' => 'El registro ya no existe.'], 404);
            }

            $ok = $modelo->eliminar((int) $id);
            if (!$ok) {
                $this->json(['ok' => false, 'mensaje' => 'No se pudo eliminar el registro.'], 500);
            }

            $this->json([
                'ok'      => true,
                'mensaje' => 'Registro eliminado correctamente.',
                'id'      => (int) $id,
            ]);
        } catch (Throwable $e) {
            $this->json(['ok' => false, 'mensaje' => 'Error al eliminar el registro.'], 500);
        }
    }

    {
        $config = self::config();
        $esperadoUser = (string) ($config['usuario'] ?? '');
        $esperadoPass = (string) ($config['password'] ?? '');

        if ($usuario === '' || $password === '') {

        }

        if (!hash_equals($esperadoUser, $usuario) || !hash_equals($esperadoPass, $password)) {
            return false;
        }

        session_regenerate_id(true);
        $_SESSION[self::SESSION_KEY] = [
            'usuario'  => $esperadoUser,
            'login_at' => time(),
        ];

        return true;
    }

    public static function check(): bool
    {
        return !empty($_SESSION[self::SESSION_KEY]['usuario']);
    }

    public static function user(): ?string
    {
        return $_SESSION[self::SESSION_KEY]['usuario'] ?? null;
    }

    public static function logout(): void
    {
        unset($_SESSION[self::SESSION_KEY]);
        session_regenerate_id(true);
    }

    public static function asistenciaHabilitada(): bool
    {
        $config = self::config();

        if (array_key_exists('forzar_asistencia', $config) && $config['forzar_asistencia'] !== null) {
            return (bool) $config['forzar_asistencia'];
        }

        $evento = (string) ($config['evento_fecha'] ?? '2026-11-06');
        $hoy = (new \DateTimeImmutable('today'))->format('Y-m-d');

namespace App\Core;

abstract class Controller
{
    protected function view(string $view, array $data = [], ?string $layout = 'layouts/header'): void
    {
        extract($data, EXTR_SKIP);

        $viewFile = dirname(__DIR__) . '/views/' . str_replace('.', '/', $view) . '.php';

        if (!is_file($viewFile)) {
            http_response_code(500);
            echo 'Vista no encontrada.';
            return;
        }

        if ($layout !== null) {
            $header = dirname(__DIR__) . '/views/layouts/header.php';
            $footer = dirname(__DIR__) . '/views/layouts/footer.php';
            require $header;
            require $viewFile;
            require $footer;
            return;
        }

        require $viewFile;
    }

    protected function json(array $payload, int $status = 200): void
    {
        http_response_code($status);
        header('Content-Type: application/json; charset=utf-8');
        header('X-Content-Type-Options: nosniff');
        echo json_encode($payload, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);
        exit;
    }

    protected function redirect(string $path): void
    {
        header('Location: ' . $path);
        exit;
    }

    protected function isPost(): bool
    {
        return strtoupper($_SERVER['REQUEST_METHOD'] ?? 'GET') === 'POST';
    }

    protected function isAjax(): bool
    {
        $requestedWith = $_SERVER['HTTP_X_REQUESTED_WITH'] ?? '';
        $accept = $_SERVER['HTTP_ACCEPT'] ?? '';

        return strcasecmp($requestedWith, 'XMLHttpRequest') === 0
            || str_contains($accept, 'application/json');
    }

    protected function csrfToken(): string
    {
        if (empty($_SESSION['_csrf'])) {
            $_SESSION['_csrf'] = bin2hex(random_bytes(32));
        }

        return $_SESSION['_csrf'];
    }

    protected function verifyCsrf(?string $token): bool
    {
        if ($token === null || empty($_SESSION['_csrf'])) {
            return false;
        }

        return hash_equals($_SESSION['_csrf'], $token);
    }

    protected function input(string $key, mixed $default = null): mixed
    {
        return $_POST[$key] ?? $_GET[$key] ?? $default;
    }
}

<?php

declare(strict_types=1);

namespace App\Core;

/**
 * Enrutador simple para el front controller.
 */
final class Router
{
    /** @var array<string, array<string, array{0: class-string, 1: string}>> */
    private array $routes = [];

    public function get(string $path, array $handler): void
    {
        $this->routes['GET'][$this->normalize($path)] = $handler;
    }

    public function post(string $path, array $handler): void
    {
        $this->routes['POST'][$this->normalize($path)] = $handler;
    }

    public function dispatch(string $uri, string $method): void
    {
        $path = parse_url($uri, PHP_URL_PATH) ?: '/';
        $path = $this->normalize($path);
        $method = strtoupper($method);

        // Quitar prefijo /public si el DocumentRoot no apunta a public/
        if (str_starts_with($path, '/public')) {
            $path = substr($path, 7) ?: '/';
            $path = $this->normalize($path);
        }

        $class = null;
        $action = null;
        $params = [];

        if (isset($this->routes[$method][$path])) {
            [$class, $action] = $this->routes[$method][$path];
        } else {
            $matched = $this->matchDynamic($method, $path);
            if ($matched !== null) {
                [$class, $action, $params] = $matched;
            }
        }

        if ($class === null || $action === null) {
            http_response_code(404);
            echo 'Página no encontrada.';
            return;
        }

        if (!class_exists($class)) {
            http_response_code(500);
            echo 'Controlador no disponible.';
            return;
        }

        $controller = new $class();

        if (!method_exists($controller, $action)) {
            http_response_code(500);
            echo 'Acción no disponible.';
            return;
        }

        $controller->{$action}(...$params);
    }

    /**
     * @return array{0: class-string, 1: string, 2: list<string>}|null
     */
    private function matchDynamic(string $method, string $path): ?array
    {
        foreach ($this->routes[$method] ?? [] as $route => $handler) {
            if (!str_contains($route, '{')) {
                continue;
            }

            $pattern = preg_replace('#\{([a-zA-Z_]+)\}#', '([^/]+)', $route);
            $pattern = '#^' . $pattern . '$#';

            if (preg_match($pattern, $path, $matches)) {
                array_shift($matches);
                return [$handler[0], $handler[1], array_values($matches)];
            }
        }

        return null;
    }

    private function normalize(string $path): string
    {
        $path = '/' . trim($path, '/');
        return $path === '/' ? '/' : rtrim($path, '/');
    }
}

<?php

declare(strict_types=1);

namespace App\Core;

/**
 * Validación y sanitización de entradas del formulario de registro.
 */
final class Validator
{
    /** @var array<string, string> */
    private array $errors = [];

    /** @var array<string, mixed> */
    private array $data = [];

    public function validateRegistro(array $input): bool
    {
        $this->errors = [];
        $this->data = [];

        $cedula = $this->clean($input['cedula'] ?? '');
        $nombre = $this->clean($input['nombre'] ?? '');
        $apellido = $this->clean($input['apellido'] ?? '');
        $fechaNacimiento = $this->clean($input['fecha_nacimiento'] ?? '');
        $correo = strtolower($this->clean($input['correo'] ?? ''));
        $telefono = $this->clean($input['telefono'] ?? '');

        // Cédula: solo dígitos, máximo 10
        $cedulaNorm = preg_replace('/\D+/', '', $cedula) ?? '';
        if ($cedulaNorm === '' || !preg_match('/^[0-9]{6,10}$/', $cedulaNorm)) {
            $this->errors['cedula'] = 'La cédula debe contener solo números (entre 6 y 10 dígitos).';
        } else {
            $this->data['cedula'] = $cedulaNorm;
        }

        // Solo primer nombre (sin espacios), máx. 30
        if ($nombre === '' || mb_strlen($nombre) < 2 || mb_strlen($nombre) > 30) {
            $this->errors['nombre'] = 'El primer nombre debe tener entre 2 y 30 caracteres.';
        } elseif (!preg_match('/^[\p{L}\'\-]+$/u', $nombre)) {
            $this->errors['nombre'] = 'Solo primer nombre: únicamente letras (sin espacios ni números).';
        } else {
            $this->data['nombre'] = mb_convert_case($nombre, MB_CASE_TITLE, 'UTF-8');
        }

        // Solo primer apellido (sin espacios), máx. 30
        if ($apellido === '' || mb_strlen($apellido) < 2 || mb_strlen($apellido) > 30) {
            $this->errors['apellido'] = 'El primer apellido debe tener entre 2 y 30 caracteres.';
        } elseif (!preg_match('/^[\p{L}\'\-]+$/u', $apellido)) {
            $this->errors['apellido'] = 'Solo primer apellido: únicamente letras (sin espacios ni números).';
        } else {
            $this->data['apellido'] = mb_convert_case($apellido, MB_CASE_TITLE, 'UTF-8');
        }

        if ($fechaNacimiento === '' || !preg_match('/^\d{4}-\d{2}-\d{2}$/', $fechaNacimiento)) {
            $this->errors['fecha_nacimiento'] = 'La fecha de nacimiento es obligatoria (AAAA-MM-DD).';
        } else {
            $fecha = \DateTimeImmutable::createFromFormat('Y-m-d', $fechaNacimiento);
            $errors = \DateTimeImmutable::getLastErrors();
            $invalid = ($errors['warning_count'] ?? 0) > 0 || ($errors['error_count'] ?? 0) > 0;

            if ($fecha === false || $invalid || $fecha->format('Y-m-d') !== $fechaNacimiento) {
                $this->errors['fecha_nacimiento'] = 'La fecha de nacimiento no es válida.';
            } else {
                $hoy = new \DateTimeImmutable('today');
                if ($fecha > $hoy) {
                    $this->errors['fecha_nacimiento'] = 'La fecha de nacimiento no puede ser futura.';
                } else {
                    $edad = (int) $fecha->diff($hoy)->y;
                    if ($edad < 12 || $edad > 100) {
                        $this->errors['fecha_nacimiento'] = 'La edad debe estar entre 12 y 100 años.';
                    } else {
                        $this->data['fecha_nacimiento'] = $fechaNacimiento;
                        $this->data['edad'] = $edad;
                    }
                }
            }
        }

        if ($correo === '' || !filter_var($correo, FILTER_VALIDATE_EMAIL)) {
            $this->errors['correo'] = 'El correo electrónico no es válido.';
        } elseif (mb_strlen($correo) > 150) {
            $this->errors['correo'] = 'El correo electrónico es demasiado largo.';
        } else {
            $this->data['correo'] = $correo;
        }

        // Teléfono: solo números
        $telefonoNorm = preg_replace('/\D+/', '', $telefono) ?? '';
        if ($telefonoNorm === '' || !preg_match('/^[0-9]{7,15}$/', $telefonoNorm)) {
            $this->errors['telefono'] = 'El teléfono debe contener solo números (entre 7 y 15 dígitos).';
        } else {
            $this->data['telefono'] = $telefonoNorm;
        }

        $this->validarInstitucion($input);

        return $this->errors === [];
    }

    /** @param array<string, mixed> $input */
    private function validarInstitucion(array $input): void
    {
        $vieneRaw = strtolower($this->clean((string) ($input['viene_institucion'] ?? '')));
        $tiposValidos = ['universidad', 'empresa', 'otra'];
        $defaultNombre = 'No indicó institución';

        if ($vieneRaw === '' || $vieneRaw === 'no') {
            $this->data['institution_name'] = $defaultNombre;
            $this->data['institution_type'] = 'no_indico';
            return;
        }

        if (!in_array($vieneRaw, ['si', 'sí', 'yes', '1'], true)) {
            $this->errors['viene_institucion'] = 'Seleccione Si o No.';
            return;
        }

        $tipo = strtolower($this->clean((string) ($input['institution_type'] ?? '')));
        if (!in_array($tipo, $tiposValidos, true)) {
            $this->errors['institution_type'] = 'Indique si viene de universidad, empresa u otra institución.';
        } else {
            $this->data['institution_type'] = $tipo;
        }

        $nombre = $this->clean((string) ($input['institution_name'] ?? ''));
        $nombre = preg_replace('/\s+/u', ' ', $nombre) ?? '';

        if ($nombre === '' || mb_strlen($nombre) < 2) {
            $this->errors['institution_name'] = 'Indique la universidad, empresa o institución de la que viene.';
        } elseif (mb_strlen($nombre) > 150) {
            $this->errors['institution_name'] = 'El nombre de la institución es demasiado largo.';
        } else {
            $this->data['institution_name'] = $nombre;
        }

        if (!isset($this->data['institution_name'])) {
            $this->data['institution_name'] = $defaultNombre;
        }
        if (!isset($this->data['institution_type'])) {
            $this->data['institution_type'] = 'no_indico';
        }
    }

    /** @return array<string, string> */
    public function errors(): array
    {
        return $this->errors;
    }

    /** @return array<string, mixed> */
    public function data(): array
    {
        return $this->data;
    }

    public function firstError(): string
    {
        return $this->errors === [] ? '' : (string) reset($this->errors);
    }

    private function clean(string $value): string
    {
        $value = trim($value);
        return preg_replace('/[\x00-\x1F\x7F]/u', '', $value) ?? '';
    }
}

class AsistenciaModel
{
    private PDO $db;

    {
        $this->db = Database::getInstance();
    }

    /**
     * Actualiza el flag asistio de forma transaccional.
     *
     * @return array{id: int, asistio: bool}|null
     */
    public function actualizarAsistencia(int $id, bool $asistio): ?array
    {
        $sql = 'UPDATE estudiantes
                SET asistio = :asistio
                WHERE id = :id
                RETURNING id, asistio';

        try {
            Database::beginTransaction();

            $stmt = $this->db->prepare($sql);
            // PostgreSQL PDO: boolean como 't'/'f' evita ambigüedad del driver
            $stmt->bindValue(':asistio', $asistio ? 't' : 'f', PDO::PARAM_STR);
            $stmt->bindValue(':id', $id, PDO::PARAM_INT);
            $stmt->execute();

            $row = $stmt->fetch();

            if ($row === false) {
                Database::rollBack();
                return null;
            }

            Database::commit();

            return [
                'id'      => (int) $row['id'],
                'asistio' => filter_var($row['asistio'], FILTER_VALIDATE_BOOLEAN),
            ];
        } catch (PDOException $e) {
            Database::rollBack();
            throw new RuntimeException('No se pudo actualizar la asistencia.', 500, $e);
        }
    }

    public function haAsistido(int $id): bool
    {
        $stmt = $this->db->prepare(
            'SELECT asistio FROM estudiantes WHERE id = :id LIMIT 1'
        );
        $stmt->bindValue(':id', $id, PDO::PARAM_INT);
        $stmt->execute();

        $value = $stmt->fetchColumn();
        if ($value === false) {
            return false;
        }

        return filter_var($value, FILTER_VALIDATE_BOOLEAN);
    }
}

     * @param array{

     *   nombre: string,
     *   apellido: string,

            $institutionName = self::DEFAULT_INSTITUTION;
        }
        $institutionType = strtolower(trim((string) ($data['institution_type'] ?? 'no_indico')));
        if (!in_array($institutionType, ['universidad', 'empresa', 'otra', 'no_indico'], true)) {
            $institutionType = 'no_indico';
        }

        $sql = 'INSERT INTO estudiantes
                (cedula, nombre, apellido, fecha_nacimiento, edad, correo, telefono,
                 institution_name, institution_type)
                VALUES
                (:cedula, :nombre, :apellido, :fecha_nacimiento, :edad, :correo, :telefono,
                 :institution_name, :institution_type)
                RETURNING id';

        try {
            Database::beginTransaction();

            $stmt = $this->db->prepare($sql);
            $stmt->bindValue(':cedula', $data['cedula'], PDO::PARAM_STR);
            $stmt->bindValue(':nombre', $data['nombre'], PDO::PARAM_STR);
            $stmt->bindValue(':apellido', $data['apellido'], PDO::PARAM_STR);
            $stmt->bindValue(':fecha_nacimiento', $data['fecha_nacimiento'], PDO::PARAM_STR);
            $stmt->bindValue(':edad', $data['edad'], PDO::PARAM_INT);
            $stmt->bindValue(':correo', $data['correo'], PDO::PARAM_STR);
            $stmt->bindValue(':telefono', $data['telefono'], PDO::PARAM_STR);
            $stmt->bindValue(':institution_name', $institutionName, PDO::PARAM_STR);
            $stmt->bindValue(':institution_type', $institutionType, PDO::PARAM_STR);
            $stmt->execute();

            $id = (int) $stmt->fetchColumn();
            Database::commit();

            return $id;
        } catch (PDOException $e) {
            Database::rollBack();

            // Violación de unicidad (cedula)
            if ($e->getCode() === '23505') {
                throw new RuntimeException('Ya existe un registro con esa cédula.', 409, $e);
            }

            error_log('Error al guardar estudiante: ' . $e->getMessage());
            throw new RuntimeException('Error al guardar el registro.', 500, $e);
        }
    }

    public function existePorCedula(string $cedula): bool
    {
        $stmt = $this->db->prepare('SELECT 1 FROM estudiantes WHERE cedula = :cedula LIMIT 1');
        $stmt->bindValue(':cedula', $cedula, PDO::PARAM_STR);
        $stmt->execute();

        return (bool) $stmt->fetchColumn();
    }

    /** @return list<array<string, mixed>> */
    public function listarTodos(): array
    {
        $stmt = $this->db->query(
            'SELECT id, cedula, nombre, apellido, fecha_nacimiento, edad, correo, telefono,
                    institution_name, institution_type, asistio, fecha_registro
             FROM estudiantes
             ORDER BY apellido ASC, nombre ASC'
        );

        return $stmt->fetchAll();
    }

    public function buscarPorId(int $id): ?array
    {
        $stmt = $this->db->prepare(
            'SELECT id, cedula, nombre, apellido, fecha_nacimiento, edad, correo, telefono,
                    institution_name, institution_type, asistio, fecha_registro
             FROM estudiantes
             WHERE id = :id
             LIMIT 1'
        );
        $stmt->bindValue(':id', $id, PDO::PARAM_INT);
        $stmt->execute();

        $row = $stmt->fetch();
        return $row === false ? null : $row;
    }

    public function buscarPorCedula(string $cedula): ?array
    {
        $stmt = $this->db->prepare(
            'SELECT id, cedula, nombre, apellido, fecha_nacimiento, edad, correo, telefono,
                    institution_name, institution_type, asistio, fecha_registro
             FROM estudiantes
             WHERE cedula = :cedula
             LIMIT 1'
        );
        $stmt->bindValue(':cedula', $cedula, PDO::PARAM_STR);
        $stmt->execute();

        $row = $stmt->fetch();
        return $row === false ? null : $row;
    }

    public function eliminar(int $id): bool
    {
        try {
            Database::beginTransaction();

            $stmt = $this->db->prepare('DELETE FROM estudiantes WHERE id = :id');
            $stmt->bindValue(':id', $id, PDO::PARAM_INT);
            $stmt->execute();
            $deleted = $stmt->rowCount() > 0;

            Database::commit();

            return $deleted;
        } catch (PDOException $e) {
            Database::rollBack();
            throw new RuntimeException('No se pudo eliminar el registro.', 500, $e);
        }
    }
}

BEGIN;

CREATE TABLE IF NOT EXISTS estudiantes (
    id               SERIAL PRIMARY KEY,
    cedula           VARCHAR(10)  NOT NULL,
    nombre           VARCHAR(30)  NOT NULL,
    apellido         VARCHAR(30)  NOT NULL,
    fecha_nacimiento DATE         NOT NULL,
    edad             INT          NOT NULL CHECK (edad >= 0 AND edad <= 120),
    correo           VARCHAR(150) NOT NULL,
    telefono         VARCHAR(15)  NOT NULL,
    institution_name VARCHAR(150) NOT NULL DEFAULT 'No indicó institución',
    institution_type VARCHAR(20)  NOT NULL DEFAULT 'no_indico',
    asistio          BOOLEAN      NOT NULL DEFAULT FALSE,
    fecha_registro   TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT uq_estudiantes_cedula UNIQUE (cedula),
    CONSTRAINT chk_estudiantes_correo CHECK (
        correo ~* '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$'
    ),
    CONSTRAINT chk_estudiantes_cedula CHECK (
        cedula ~ '^[0-9]{6,10}$'
    ),
    CONSTRAINT chk_estudiantes_telefono CHECK (
        telefono ~ '^[0-9]{7,15}$'
    ),
    CONSTRAINT chk_estudiantes_nombre CHECK (
        char_length(trim(nombre)) BETWEEN 2 AND 30
        AND nombre ~ '^[[:alpha:]''\-]+$'
    ),
    CONSTRAINT chk_estudiantes_apellido CHECK (
        char_length(trim(apellido)) BETWEEN 2 AND 30
        AND apellido ~ '^[[:alpha:]''\-]+$'
    )
);

CREATE INDEX IF NOT EXISTS idx_estudiantes_apellido ON estudiantes (apellido);
CREATE INDEX IF NOT EXISTS idx_estudiantes_asistio ON estudiantes (asistio);
CREATE INDEX IF NOT EXISTS idx_estudiantes_cedula ON estudiantes (cedula);
CREATE INDEX IF NOT EXISTS idx_estudiantes_institution_type ON estudiantes (institution_type);

COMMENT ON COLUMN estudiantes.institution_name IS 'Universidad, empresa o institución de procedencia';
COMMENT ON COLUMN estudiantes.institution_type IS 'universidad | empresa | otra | no_indico';

  const EMAIL_RE = /^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$/;

  });

  function soloDigitos(value, max) {
    return String(value || "").replace(/\D+/g, "").slice(0, max);
  }

  function soloLetrasNombre(value, max) {
    return String(value || "")
      .replace(/[^\p{L}'\-]/gu, "")
      .slice(0, max);
  }

  function calcularEdad(fechaISO) {
    if (!fechaISO) return "";
    const nacimiento = new Date(fechaISO + "T00:00:00");
    if (Number.isNaN(nacimiento.getTime())) return "";

    const hoy = new Date();
    let edad = hoy.getFullYear() - nacimiento.getFullYear();
    const m = hoy.getMonth() - nacimiento.getMonth();
    if (m < 0 || (m === 0 && hoy.getDate() < nacimiento.getDate())) {
      edad -= 1;
    }
    return edad >= 0 ? String(edad) : "";
  }

  function setError(field, message) {
    const slot = document.querySelector(`[data-error-for="${field.id}"]`);
    field.classList.toggle("is-invalid", Boolean(message));
    if (slot) slot.textContent = message || "";
  }

  function clearErrors(form) {
    form.querySelectorAll(".is-invalid").forEach((f) => f.classList.remove("is-invalid"));
    form.querySelectorAll(".field-error").forEach((e) => {
      e.textContent = "";
    });
  }

  function showAlert(el, message, type) {
    if (!el) return;
    const bsType = type === "error" ? "danger" : type;
    el.textContent = message;
    el.className = `alert alert-${bsType} show`;
    el.classList.remove("d-none");
  }

  function validarRegistro(form) {
    clearErrors(form);
    let ok = true;

    const nombre = soloLetrasNombre(form.nombre.value.trim(), 30);
    const apellido = soloLetrasNombre(form.apellido.value.trim(), 30);
    const fecha = form.fecha_nacimiento.value;
    const correo = form.correo.value.trim().toLowerCase();
    const telefono = soloDigitos(form.telefono.value, 15);
    const viene = String(form.viene_institucion?.value || "").toLowerCase();

    form.cedula.value = cedula;
    form.nombre.value = nombre;
    form.apellido.value = apellido;
    form.correo.value = correo;
    form.telefono.value = telefono;

    if (!CEDULA_RE.test(cedula)) {
      setError(form.cedula, "La cédula debe tener solo números (6 a 10 dígitos).");
      ok = false;
    }

    if (nombre.length < 2 || !NOMBRE_RE.test(nombre)) {
      setError(form.nombre, "Ingrese solo su primer nombre (letras, máx. 30).");
      ok = false;
    }

    if (apellido.length < 2 || !NOMBRE_RE.test(apellido)) {
      setError(form.apellido, "Ingrese solo su primer apellido (letras, máx. 30).");
      ok = false;
    }

    const edad = Number(calcularEdad(fecha));
    if (!fecha || Number.isNaN(edad) || edad < 12 || edad > 100) {
      setError(form.fecha_nacimiento, "Fecha inválida. La edad debe estar entre 12 y 100 años.");
      ok = false;
    }

    if (!EMAIL_RE.test(correo)) {
      setError(form.correo, "Correo electrónico inválido.");
      ok = false;
    }

    if (!TELEFONO_RE.test(telefono)) {
      setError(form.telefono, "El teléfono debe tener solo números (7 a 15 dígitos).");
      ok = false;
    }

    if (viene === "si" || viene === "sí") {
      const tipo = String(form.institution_type?.value || "");
      const instNombre = String(form.institution_name?.value || "").trim();
      if (!["universidad", "empresa", "otra"].includes(tipo)) {
        setError(form.institution_type, "Indique si viene de universidad, empresa u otra institución.");
        ok = false;
      }
      if (instNombre.length < 2) {
        setError(form.institution_name, "Indique la universidad, empresa o institución de la que viene.");
        ok = false;
      }
    }

    return ok;
  }

    const show = viene === "si" || viene === "sí";
    document.querySelectorAll(".inst-extra").forEach((el) => {
      el.classList.toggle("d-none", !show);

    if (!show && form.institution_name) {

      if (form.institution_type) form.institution_type.value = "";
    }

  function initRegistro() {
    const form = document.getElementById("form-registro");
    if (!form) return;

    const fecha = form.fecha_nacimiento;
    const edadInput = form.edad;
    const alerta = document.getElementById("alerta");
    const btn = document.getElementById("btn-registrar");

    form.cedula.addEventListener("input", () => {
      form.cedula.value = soloDigitos(form.cedula.value, 10);
    });
    form.telefono.addEventListener("input", () => {
      form.telefono.value = soloDigitos(form.telefono.value, 15);
    });
    form.nombre.addEventListener("input", () => {
      form.nombre.value = soloLetrasNombre(form.nombre.value, 30);
    });
    form.apellido.addEventListener("input", () => {
      form.apellido.value = soloLetrasNombre(form.apellido.value, 30);
    });

    const syncEdad = () => {
      edadInput.value = calcularEdad(fecha.value);
    };

    fecha.addEventListener("change", syncEdad);
    fecha.addEventListener("input", syncEdad);
    syncEdad();

    if (form.viene_institucion) {
      form.viene_institucion.addEventListener("change", () => toggleInstitucion(form));
      toggleInstitucion(form);
    }

    document.querySelectorAll("[data-close-modal]").forEach((el) => {
      el.addEventListener("click", closeSuccessModal);
    });

    form.addEventListener("submit", async (event) => {
      event.preventDefault();

      if (!validarRegistro(form)) {
        showAlert(alerta, "Revise los campos del formulario.", "error");
        return;
      }

      btn.disabled = true;
      const original = btn.textContent;
      btn.textContent = "Guardando…";

      try {
        const body = new FormData(form);
        const response = await fetch("/registro", {
          method: "POST",
          headers: {
            Accept: "application/json",
            "X-Requested-With": "XMLHttpRequest",
          },
          body,
        });

        const data = await response.json().catch(() => null);

        if (!response.ok || !data?.ok) {
          if (data?.errores) {
            Object.entries(data.errores).forEach(([key, msg]) => {
              const field = form.elements.namedItem(key);
              if (field && field instanceof HTMLElement) setError(field, msg);
            });
          }
          showAlert(alerta, data?.mensaje || "No se pudo completar el registro.", "error");
          return;
        }

        form.reset();
        edadInput.value = "";
        toggleInstitucion(form);
        clearErrors(form);
        if (alerta) alerta.classList.add("d-none");
        openSuccessModal(data.mensaje);
      } catch (err) {
        showAlert(alerta, "Error de red. Intente nuevamente.", "error");
      } finally {
        btn.disabled = false;
        btn.textContent = original;
      }
    });
  }

  function escapeHtml(str) {
    return String(str)
      .replace(/&/g, "&amp;")
      .replace(/</g, "&lt;")
      .replace(/>/g, "&gt;")
      .replace(/"/g, "&quot;");
  }

  function initLogistica() {
    const tabla = document.getElementById("tabla-asistencia");
    const tbody = document.getElementById("tbody-estudiantes");
    const buscador = document.getElementById("buscador");
    const csrf = document.getElementById("csrf-logistica");
    const toast = document.getElementById("toast-logistica");
    if (!tabla || !tbody || !csrf) return;

    let asistenciaHabilitada = tabla.dataset.asistencia === "1";
    let filtroTipo = "todos";
    let pendingDeleteId = null;

    const mostrarToast = (msg, isError = false) => {
      if (!toast) return;
      toast.textContent = msg;
      toast.classList.toggle("is-error", isError);
      toast.classList.add("is-visible");
      clearTimeout(mostrarToast._t);
      mostrarToast._t = setTimeout(() => toast.classList.remove("is-visible"), 2800);
    };

    const labelTipo = (tipo) => {
      if (tipo === "universidad") return "Universidad";
      if (tipo === "empresa") return "Empresa";
      if (tipo === "otra") return "Otra institución";
      return "No indicó";
    };

    const aplicarFiltro = () => {
      const q = buscador ? buscador.value.trim().toLowerCase() : "";
      tbody.querySelectorAll("tr").forEach((row) => {
        if (row.classList.contains("empty-row")) return;
        const cedula = row.dataset.cedula || "";
        const apellido = row.dataset.apellido || "";
        const tipo = row.dataset.tipo || "no_indico";
        const matchTexto = !q || cedula.includes(q) || apellido.includes(q);
        const matchTipo = filtroTipo === "todos" || tipo === filtroTipo;
        row.classList.toggle("is-hidden", !(matchTexto && matchTipo));
      });
    };

    const formatFecha = (raw) => {
      if (!raw) return "—";
      const d = new Date(raw);
      if (Number.isNaN(d.getTime())) return "—";
      const pad = (n) => String(n).padStart(2, "0");
      return `${pad(d.getDate())}/${pad(d.getMonth() + 1)}/${d.getFullYear()} ${pad(d.getHours())}:${pad(d.getMinutes())}`;
    };

    const celdaInstitucion = (e) => {
      const tipo = String(e.institution_type || "no_indico");
      const nombreInst = escapeHtml(e.institution_name || "No indicó institución");
      return `<span class="badge text-bg-light border">${escapeHtml(labelTipo(tipo))}</span>
              <div class="small text-muted">${nombreInst}</div>`;
    };

    const botonEliminar = (e, nombre, apellido) =>
      `<button type="button" class="btn btn-sm btn-outline-danger btn-eliminar" data-id="${e.id}" data-nombre="${nombre} ${apellido}">Eliminar</button>`;

    const renderFilas = (estudiantes) => {
      const cols = asistenciaHabilitada ? 9 : 8;
      if (!estudiantes.length) {
        tbody.innerHTML = `<tr class="empty-row"><td colspan="${cols}">No hay participantes registrados aún.</td></tr>`;
        return;
      }

      tbody.innerHTML = estudiantes
        .map((e) => {
          const nombre = escapeHtml(e.nombre);
          const apellido = escapeHtml(e.apellido);
          const cedula = escapeHtml(e.cedula);
          const correo = escapeHtml(e.correo);
          const telefono = escapeHtml(e.telefono);
          const cedulaKey = String(e.cedula).toLowerCase();
          const apellidoKey = String(e.apellido).toLowerCase();
          const tipo = escapeHtml(String(e.institution_type || "no_indico"));
          const inst = celdaInstitucion(e);
          const eliminar = botonEliminar(e, nombre, apellido);

          if (asistenciaHabilitada) {
            const cert = e.asistio
              ? `<a class="btn btn-sm btn-outline-primary" href="/certificados/${e.id}" target="_blank" rel="noopener">Ver</a>`
              : `<span class="text-muted">—</span>`;
            const selectHtml = e.asistio
              ? `<select class="form-select form-select-sm select-asistencia" data-id="${e.id}" disabled title="Asistencia confirmada: no se puede modificar" aria-label="Asistencia confirmada de ${nombre} ${apellido}">
                  <option value="1" selected>Sí</option>
                </select>`
              : `<select class="form-select form-select-sm select-asistencia" data-id="${e.id}" aria-label="Asistencia de ${nombre} ${apellido}">
                  <option value="0" selected>No</option>
                  <option value="1">Sí</option>
                </select>`;
            return `<tr data-id="${e.id}" data-cedula="${escapeHtml(cedulaKey)}" data-apellido="${escapeHtml(apellidoKey)}" data-tipo="${tipo}">
              <td>${cedula}</td><td>${apellido}</td><td>${nombre}</td><td>${correo}</td><td>${telefono}</td>
              <td>${inst}</td>
              <td>${selectHtml}</td>
              <td class="cell-cert">${cert}</td>
              <td>${eliminar}</td>
            </tr>`;
          }

          return `<tr data-id="${e.id}" data-cedula="${escapeHtml(cedulaKey)}" data-apellido="${escapeHtml(apellidoKey)}" data-tipo="${tipo}">
            <td>${cedula}</td><td>${apellido}</td><td>${nombre}</td><td>${correo}</td><td>${telefono}</td>
            <td>${inst}</td>
            <td>${escapeHtml(formatFecha(e.fecha_registro))}</td>
            <td>${eliminar}</td>
          </tr>`;
        })
        .join("");

      aplicarFiltro();
    };

    const actualizarStats = (total, asistentes) => {
      const totalEl = document.getElementById("stat-total");
      const asisEl = document.getElementById("stat-asistentes");
      if (totalEl) totalEl.textContent = String(total);
      if (asisEl) asisEl.textContent = String(asistentes);
    };

    const refrescarLista = async () => {
      try {
        const response = await fetch("/logistica/lista", {
          headers: { Accept: "application/json", "X-Requested-With": "XMLHttpRequest" },
        });
        if (response.status === 401) {
          window.location.href = "/login";
          return;
        }
        const data = await response.json().catch(() => null);
        if (!response.ok || !data?.ok) return;

        const prevAsistencia = asistenciaHabilitada;
        asistenciaHabilitada = Boolean(data.asistencia_habilitada);
        if (prevAsistencia !== asistenciaHabilitada) {
          window.location.reload();
          return;
        }

        // Conservar valores de selects en edición local no es crítico; re-render limpio
        const focused = document.activeElement;
        const editingSelect =
          focused instanceof HTMLSelectElement && focused.classList.contains("select-asistencia");
        if (editingSelect) return;

        renderFilas(data.estudiantes || []);
        actualizarStats(data.total ?? 0, data.asistentes ?? 0);
      } catch (err) {
        /* silencio: el panel sigue usable offline temporalmente */
      }
    };

    if (buscador) {
      buscador.addEventListener("input", aplicarFiltro);
    }

    document.querySelectorAll(".filtro-tipo").forEach((btn) => {
      btn.addEventListener("click", () => {
        filtroTipo = btn.dataset.tipo || "todos";
        document.querySelectorAll(".filtro-tipo").forEach((b) => {
          const active = b === btn;
          b.classList.toggle("is-active", active);
          b.classList.toggle("btn-primary", active);
          b.classList.toggle("btn-outline-primary", !active);
        });
        aplicarFiltro();
      });
    });

    const modalEliminar = document.getElementById("modal-eliminar");
    const textoEliminar = document.getElementById("modal-eliminar-texto");
    const btnConfirmarEliminar = document.getElementById("btn-confirmar-eliminar");

    const openDeleteModal = (id, nombre) => {
      pendingDeleteId = id;
      if (textoEliminar) {
        textoEliminar.textContent = `¿Seguro que desea eliminar a ${nombre}? Esta acción no se puede deshacer.`;
      }
      if (modalEliminar) {
        modalEliminar.hidden = false;
        modalEliminar.classList.add("is-open");
      }
    };

    const closeDeleteModal = () => {
      pendingDeleteId = null;
      if (modalEliminar) {
        modalEliminar.classList.remove("is-open");
        modalEliminar.hidden = true;
      }
    };

    tbody.addEventListener("click", (event) => {
      const btn = event.target instanceof Element ? event.target.closest(".btn-eliminar") : null;
      if (!btn) return;
      openDeleteModal(btn.dataset.id, btn.dataset.nombre || "este asistente");
    });

    document.querySelectorAll("[data-close-confirm]").forEach((el) => {
      el.addEventListener("click", closeDeleteModal);
    });

    if (btnConfirmarEliminar) {
      btnConfirmarEliminar.addEventListener("click", async () => {
        const id = pendingDeleteId;
        if (!id) return;
        btnConfirmarEliminar.disabled = true;
        try {
          const response = await fetch("/logistica/eliminar", {
            method: "POST",
            headers: {
              Accept: "application/json",
              "Content-Type": "application/json",
              "X-Requested-With": "XMLHttpRequest",
            },
            body: JSON.stringify({ id: Number(id), _csrf: csrf.value }),
          });
          const data = await response.json().catch(() => null);
          if (!response.ok || !data?.ok) {
            mostrarToast(data?.mensaje || "No se pudo eliminar el registro.", true);
            if (response.status === 401) window.location.href = "/login";
            return;
          }
          closeDeleteModal();
          mostrarToast(data.mensaje || "Registro eliminado.");
          const row = tbody.querySelector(`tr[data-id="${id}"]`);
          if (row) row.remove();
          const totalEl = document.getElementById("stat-total");
          if (totalEl) {
            const n = tbody.querySelectorAll("tr:not(.empty-row)").length;
            totalEl.textContent = String(n);
          }
        } catch (err) {
          mostrarToast("Error de red al eliminar.", true);
        } finally {
          btnConfirmarEliminar.disabled = false;
        }
      });
    }

    tabla.addEventListener("change", async (event) => {
      const select = event.target;
      if (!(select instanceof HTMLSelectElement) || !select.classList.contains("select-asistencia")) {
        return;
      }

      if (select.disabled) return;

      const id = select.dataset.id;
      const asistio = select.value === "1";
      const prev = "0";

      // Solo se permite confirmar (Sí). Si vuelve a No, revertir.
      if (!asistio) {
        select.value = prev;
        return;
      }

      select.disabled = true;

      try {
        const response = await fetch("/logistica/asistencia", {
          method: "POST",
          headers: {
            Accept: "application/json",
            "Content-Type": "application/json",
            "X-Requested-With": "XMLHttpRequest",
          },
          body: JSON.stringify({
            id: Number(id),
            asistio: true,
            _csrf: csrf.value,
          }),
        });

        const data = await response.json().catch(() => null);
        if (!response.ok || !data?.ok) {
          select.value = prev;
          select.disabled = false;
          mostrarToast(data?.mensaje || "No se pudo actualizar.", true);
          if (response.status === 401) window.location.href = "/login";
          return;
        }

        // Bloquear definitivamente el select
        select.innerHTML = '<option value="1" selected>Sí</option>';
        select.disabled = true;
        select.title = "Asistencia confirmada: no se puede modificar";

        const cell = select.closest("tr")?.querySelector(".cell-cert");
        if (cell) {
          cell.innerHTML = `<a class="btn btn-sm btn-outline-primary" href="/certificados/${id}" target="_blank" rel="noopener">Ver</a>`;
        }

        const asisEl = document.getElementById("stat-asistentes");
        if (asisEl) {
          const count = [...tbody.querySelectorAll(".select-asistencia")].filter((s) => s.value === "1").length;
          asisEl.textContent = String(count);
        }

        mostrarToast(data.mensaje);
      } catch (err) {
        select.value = prev;
        select.disabled = false;
        mostrarToast("Error de red al actualizar.", true);
      }
    });

    setInterval(refrescarLista, 15000);
  }
})();

(() => {
  "use strict";

  document.addEventListener("DOMContentLoaded", () => {
    const certificado = document.getElementById("certificado");
    const btnPdf = document.getElementById("btn-descargar-pdf");
    const btnPrint = document.getElementById("btn-imprimir");

    if (btnPrint) {
      btnPrint.addEventListener("click", () => window.print());
    }

    if (!btnPdf || !certificado) return;

    btnPdf.addEventListener("click", async () => {
      if (typeof PDFLib === "undefined") {
        alert("No se pudo cargar el generador de PDF. Recargue la página.");
        return;
      }

      const filename = certificado.dataset.filename || "Certificado_Asistencia.pdf";
      const nombre = certificado.dataset.nombre || "";
      const cedula = certificado.dataset.cedula || "";
      const templateUrl = certificado.dataset.template || "/img/plantilla-certificado.pdf";
      const original = btnPdf.textContent;
      btnPdf.disabled = true;
      btnPdf.textContent = "Generando PDF…";

      try {
        const res = await fetch(templateUrl);
        if (!res.ok) {
          throw new Error("No se pudo leer la plantilla PDF");
        }

        const bytes = await res.arrayBuffer();
        const pdf = await PDFLib.PDFDocument.load(bytes);
        const page = pdf.getPages()[0];
        const { width, height } = page.getSize();
        const fontBold = await pdf.embedFont(PDFLib.StandardFonts.TimesBold);
        const fontReg = await pdf.embedFont(PDFLib.StandardFonts.TimesRoman);
        const color = PDFLib.rgb(10 / 255, 33 / 255, 77 / 255);

        const fitSize = (text, font, maxSize, maxWidth) => {
          let size = maxSize;
          while (size > 10 && font.widthOfTextAtSize(text, size) > maxWidth) {
            size -= 0.5;
          }
          return size;
        };

        const maxWidth = width * 0.74;
        const nameSize = fitSize(nombre, fontBold, 22, maxWidth);
        const nameWidth = fontBold.widthOfTextAtSize(nombre, nameSize);
        page.drawText(nombre, {
          x: (width - nameWidth) / 2,
          y: height * 0.672,
          size: nameSize,
          font: fontBold,
          color,
        });

        if (cedula) {
          const cedSize = 12;
          const cedWidth = fontReg.widthOfTextAtSize(cedula, cedSize);
          page.drawText(cedula, {
            x: (width - cedWidth) / 2,
            y: height * 0.635,
            size: cedSize,
            font: fontReg,
            color,
          });
        }

        const out = await pdf.save();
        const blob = new Blob([out], { type: "application/pdf" });
        const url = URL.createObjectURL(blob);
        const a = document.createElement("a");
        a.href = url;
        a.download = filename;
        a.click();
        setTimeout(() => URL.revokeObjectURL(url), 1500);
      } catch (err) {
        console.error(err);
        alert("Ocurrió un error al generar el PDF. Intente nuevamente.");
      } finally {
        btnPdf.disabled = false;
        btnPdf.textContent = original;
      }
    });
  });
})();
